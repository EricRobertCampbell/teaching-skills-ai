# Review Math 30-1

Review Alberta **Mathematics 30-1** instructional and assessment materials (lessons, worksheets, quizzes, unit tests, diploma practice, keys).

Provincial diploma commentary (Alberta Education and Childcare, *Mathematics 30–1 Information Bulletin 2025–2026*) informs the general and unit checks below. Local copy: `diploma-reports/math-30-1-information-bulletin-2025-2026.pdf`.

## Workflow

1. Identify the unit / outcomes the material claims to address.
2. Run the **general checks** below on every item.
3. Read and apply any filled-in **unit section** that matches the material.
4. Report findings by severity; prefer concrete fixes (rewrite the prompt/notation) over vague notes.

## Report format

- **Must fix**: incorrect math, wrong level for 30-1, broken notation that misleads students
- **Should fix**: convention drift, unclear wording, weak alignment to the claimed outcome
- **Optional**: polish, wording preference, stretch/enrichment ideas

For each issue: cite the item (question number / section), state the problem, and give a corrected version when possible.

## General checks

### Course-level appropriateness

- Content belongs in **Mathematics 30-1** (Alberta), not 20-1 / 30-2 / Math 31 unless clearly labelled enrichment
- Difficulty matches the material type (intro lesson ≠ diploma multi-select ≠ unit test)
- Prerequisites assumed are already taught in this course sequence (or earlier grades)
- Outcomes match the stated unit; avoid smuggling later-unit techniques unless intentional review
- Diploma-style items use appropriate format and demand (WR vs MC/NR expectations)
- Written-response practice should mirror diploma design: multi-part items, bolded directing words, and opportunities for partial credit on incomplete but on-path work

### Mathematical notation and conventions

- Variables, functions, and parameters are named consistently (\(f(x)\), \(y=\ldots\), mappings, etc.)
- Domain / range, asymptotes, intercepts, and restrictions are stated with correct set / interval notation when required
- Equations vs expressions vs inequalities are not conflated (markers note students often simplify/factor when they should solve, or verify an identity when asked to prove)
- Inverse / composition / transformation notation is unambiguous; transformation vocabulary is written out (no informal abbreviations in explanations students are expected to imitate)
- Trig: degree vs radian mode is explicit when it matters; standard angle and identity forms are used correctly; trig expressions include the angle argument
- Logs / exponentials: base is clear; change-of-base and log laws applied with correct restrictions
- Graphs: axes labelled; key points readable; B&W-safe if print materials
- Solutions / keys match the prompt and use the course’s preferred forms (e.g. factored vs expanded when that unit cares)
- Final answers in keys include units when the context has units; necessary brackets appear; factors are set equal to zero when solving; solutions are related back to context

### Diploma written-response and directing words

When reviewing diploma-style WR items or keys, check that prompts and solutions honour official directing-word meanings (bolded on the exam):

| Directing word | Materials / keys should require |
| --- | --- |
| **Algebraically** | A complete symbolic process (not calculator-only) |
| **Compare** | Explicit similarities **and** differences with supporting evidence |
| **Determine** | Formulas, procedures, and/or calculations shown—not a bare answer |
| **Justify** | A stated position plus supporting mathematical argument |
| **Prove** | Factual evidence or logical argument establishing validity |
| **Verify** | Establishment for a particular case (e.g. substitution)—not treated as identical to prove |
| **Sketch** | Clearly drawn, scaled axes and key characteristics (vertices, endpoints, max/min, intercepts, asymptotes, correct shape/end behaviour) |

Also flag WR items that bury multiple requirements without making each component easy to attempt, or keys that reward disorganized work / missing labels.

### Diploma focus areas (cross-unit)

Prefer practice and assessment weight on provincial weak spots; keep provincial strengths as maintenance, not the only drill:

- Mapping notation for **stretches**; invariant points beyond reflections
- Combining **multiple** logarithm laws; rational functions with **holes**
- Trig equations needing **identity substitution**; identity work with conjugates, double angles, rational operations
- Counting with **three or more constraints** / multiple cases; binomial **specific terms** with non-linear parts

## Unit sections

When reviewing material for a unit, apply that section in addition to the general checks. Bullets marked **provincial gap** come from the 2025–2026 diploma commentary and should be prioritized in review feedback and suggested revisions.

### 1 — Functions and Relations

- Function vs relation language is precise; vertical-line test / uniqueness wording is correct when used
- Domain and range use proper notation; restrictions are complete
- Operations on functions (sum, difference, product, quotient, composition) match the claimed outcome level
- Keys evaluate operations at specific inputs correctly (provincial strength—still check accuracy)
- **Provincial gap:** do not treat function operations as mastered only via graphs; include exact algebraic evaluation items when the unit claims that outcome

### 2 — Transformations

- Verbal description, variable replacement, and mapping forms are named and converted consistently (see also `thinking-classrooms-transformations`)
- SRT / canonical order appears in solutions when order was ambiguous—not as a student-facing spoiler unless intended
- Mapping notation is fully simplified/expanded per course convention
- **Provincial gap:** materials that only practise mapping for translations/reflections under-serve students—include **stretches** in mapping form
- **Provincial gap:** include invariant-point items for transformations **other than** reflections (reflections alone are a provincial strength)
- Transformation explanations in keys model full vocabulary (horizontal/vertical stretch by factor \(k\), etc.), not abbreviations
- Sketch keys meet the sketch standard in General checks

### 3 — Exponential and Logarithmic Functions

- Base is explicit; domain restrictions for logs appear in solutions when required
- Change-of-base and log laws are applied with correct structure
- **Provincial strength to maintain:** exponential equations reducible to a common base; solving for a base in an exponential equation
- **Provincial gap:** items and keys that stop at single product/power law applications are too thin—include **multi-law** condense/expand and logarithmic equations needing several laws
- Check that “solve” prompts do not accept expression-simplification work in the key

### 4 — Trigonometric Functions and Graphs

- Degree vs radian is clear; coterminal / standard position / arc length items match 30-1 expectations
- **Provincial strengths to maintain:** coterminal angles, standard position, arc length; angle from one unit-circle coordinate; linking sinusoidal parameters to graph features
- Parameter ↔ amplitude / period / phase / midline language in keys is precise
- Sketch keys show scaled axes and key sinusoidal landmarks
- Contextual sinusoid items (if any) require relating features back to the situation

### 5 — Permutations and Combinations

- Restriction language (“and” / “or” / “at least”) is unambiguous; case splits in keys are exhaustive and disjoint
- **Provincial strength to maintain:** one- or two-constraint permutations; repeated-elements problems
- **Provincial gap:** include items with **three or more constraints** and/or **multiple cases**—these are where provincial performance drops
- Binomial theorem: stronger students handle statements about expansions with **linear** terms; **provincial gap:** require finding **specific terms** when binomial parts are **non-linear**
- **Determine**-style keys must show formulas/reasoning, not only a final integer

### 6 — Trigonometric Equations and Identities

- Domain of solutions is stated; extraneous roots from squaring / identities are checked
- **Provincial strength:** many first- and second-degree trig equations without identity substitution; exact values in simpler verification steps
- **Provincial gap:** equations that require an **identity substitution** before solving
- **Provincial gap:** verifying identities that need **conjugates**, **double-angle** identities, and **rational operations**
- Keys distinguish **verify** vs **prove** when the directing word requires it; include angle arguments and brackets in every trig expression

### 7 — Polynomial Functions and Equations

- Factor / remainder connections to graphs are accurate
- **Provincial strength to maintain:** determining factors of a polynomial and relating factored form to graph characteristics
- Solving vs factoring is not conflated in prompts or keys
- Multiplicity / intercept / end-behaviour language matches the graph shown

### 8 — Radical and Rational Functions

- Non-permissible values, holes, and asymptotes are distinguished correctly
- **Provincial gap:** domain and range of rational functions that contain a **point of discontinuity (hole)**—prioritize these over only vertical-asymptote examples
- Keys that cancel factors must still exclude hole \(x\)-values from the domain and account for missing \(y\)-values in the range when applicable
- Radical domain restrictions and extraneous roots after isolating/squaring are checked in solutions

## Quick diploma-alignment pass (optional)

When the material is explicitly diploma practice, also ask:

1. Does each WR part map to a directing word with matching work in the key?
2. Are provincial gaps represented at least as often as provincial strengths?
3. Would a student who only copies the key learn correct notation (mappings, domain/range, trig arguments, units)?
